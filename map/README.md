# Territory Planner / 拠点配置シミュレーター

Place Alliance Fortresses (AF) and Flags on the map to check territory connections and crystals inside your territory.

マップ上に要塞（AF）と旗（Flag）を置いて、領土のつながりと領土内の水晶の数を確認できるページです。

## ファイル
- `index.html` … シミュレーター本体
- `map.jpg` … マップ画像（4096px。スマホでも重くならないサイズ）
- `crystals.js` … 水晶の座標（1670か所、ゲーム座標）
- `extract.html` … 赤丸画像から crystals.js を作り直すツール（水晶の位置が変わったとき用）

## GitHub Pages での公開
既にGitHub Pagesを公開しているリポジトリなら、`map` フォルダを作って中身を入れるだけで動きます。
1. リポジトリで「Add file → Upload files」
2. このフォルダの中身（index.html, map.jpg, crystals.js など）を `map/` の中にアップロード
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/map/` で開けます

新しいリポジトリの場合は、Settings → Pages → Branch を `main` / `(root)` にして Save してください。

## 共有のしかた
画面右上の「📤 Share / 共有」にまとめてあります。
1. **地図を送る**：「Share link」でDiscordやLINEに送る（PCは「Copy link」で貼り付け）。開いた人は見るだけです
2. **受け取ったリンク**：タップすれば開きます。開かないときはShare画面に貼り付けて「Open」
3. **まとめ役**：届いたリンクを開いて「Add to my map」を押すと、その同盟が自分の地図に追加されます（同じ同盟名は入れ替え）
4. **サイト管理者**：「Save layout.json」で保存して index.html と同じ場所にアップロードすると、全員に「Published」として表示されます

## ルール（メニューの「ルール設定」で変更可能）
- 要塞（AF）は1同盟2つまで（AF1・AF2）
- 要塞の領土：中心から ±7（15×15マス）。旗と同じく3マス刻みに吸着（例：X 534〜548）
- 旗の領土：中心から ±4（9×9マス）。3マス単位のブロックに揃う
- 旗の中心は3マス刻み（1, 4, 7, …）
- 旗は要塞の領土、または有効な旗の領土に重なるか接している場合に有効（繋がっていない旗も置けるが、赤い点線の無効表示になる）

## 操作
- 領土は同盟の色で塗られます。濃い部分が要塞の領土です。要塞・旗のアイコンは拡大したときだけ表示されます
- ドラッグで移動、ホイール／ピンチで拡大縮小
- 「AF」「Flag」を選んでタップで配置、「選択・移動」でアイコンをドラッグして移動
- メニューから座標指定での配置、同盟の追加、共有URLのコピーができます
